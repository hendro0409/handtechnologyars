# HandTechnology ARS — Website Company Profile

Website statis gratis untuk layanan IT HandTechnology ARS. Tidak membutuhkan database atau server backend.

## Isi website
- Pembuatan Aplikasi
- Pemasangan CCTV
- Pemasangan Absensi
- Pemasangan Access Door
- Service Laptop & Komputer / Upgrade
- Maintenance Jaringan / Network
- Tampilan responsif HP, tablet, desktop
- Form konsultasi yang diarahkan ke WhatsApp
- Tombol WhatsApp mengambang
- Animasi ringan saat scroll

## WAJIB: ganti nomor WhatsApp
Buka file:
`assets/js/main.js`

Cari:
`const WHATSAPP_NUMBER = '6280000000000';`

Ganti dengan nomor Anda. Contoh:
0812-3456-7890 → `6281234567890`

## Ubah email
Cari teks `info@handtechnologyars.com` di `index.html`, lalu ganti dengan email aktif.

## Cara hosting GRATIS — GitHub Pages
1. Buat akun GitHub.
2. Buat repository baru, misalnya `handtechnology-ars`.
3. Upload seluruh isi folder website ini.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/root`, lalu Save.
7. Tunggu beberapa menit hingga URL website aktif.

## Cara hosting GRATIS — Netlify
1. Buka Netlify dan login.
2. Pilih **Add new site → Deploy manually**.
3. Drag & drop folder `handtechnology-ars` atau file ZIP-nya.
4. Website langsung mendapatkan alamat gratis `*.netlify.app`.
